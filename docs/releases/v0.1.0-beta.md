The first beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.1.0-beta.zip` below.

## What's in it

- **Borderless fullscreen:** set the game to Windowed and it covers the whole monitor. Alt-tab no longer minimizes the game or switches its display mode, and the Windows key works again.
- **Field of view:** 30–170, also as a slider in Options → Gameplay, on foot and in vehicles and exo-suits.
- **Video settings that stick:** resolution, Windowed and quality are kept between launches.
- **Developer console improvements:** mouse-wheel scrolling, and `console.ini` for settings applied at start-up and on every level load.
- **RfaEditor:** browse and extract every archive; edit tables (`.xtbl`) and replace textures; view models and animations and export them as OBJ; open levels in a 3D level editor, lit like the game, and move, add or delete objects. Changes are saved as overrides, never into the game's files.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor only: the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

## Please note

- This is a beta: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
