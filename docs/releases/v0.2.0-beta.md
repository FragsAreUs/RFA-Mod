The second beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.2.0-beta.zip` below.

## What's new since v0.1.0-beta

**Level editor**
- **Fixed: the game freezing after objects were added to a level.** The game sets memory aside for a level's files by the sizes in its asset lists, and one of the entries naming a saved zone kept its old size, so the grown zone ran into other memory. Saving now updates every entry naming the saved files. If a level you changed with v0.1.0-beta freezes the game, open it and save it again: that mends it.
- **Links between objects:** the picked object's links (navpoint paths, roads, a logic handler's triggers and targets, lights attached to buildings, ...) are drawn as lines and listed in the inspector, where a click flies to the linked object. The **Links** chip draws every link in the level.
- **Whole breakable objects:** Duplicate and Add copy a whole breakable object, from a loose piece up to what it hangs from, with everything attached and the destruction links holding it together. The copy goes beside the original. Moving and turning an object carry what is attached to it, as one undo step.
- A crash log (`logs\editor.log`), and a level opened before the editor has finished reading the game ("Ready") now gets all its textures and its game lighting, the same as one opened after.

**Loader**
- **New files:** a file in `overrides\` that the game doesn't have at all, outside any archive's folder, is given to the game when it looks for it. A new map's archive works this way: groundwork for new maps.
- **New Ruin maps:** the game starts Ruin maps by their place in its map table, not by the file name the table gives them. The loader now makes it start the map the table names. The game reads five maps, so a new map takes the place of one of the game's own. `src\overrides\README.md` (in this repository) says how.
- `LogLookups=1` under `[Loader]` in `rfa_mods.ini` logs which files a level loads (off by default).

**For developers:** the editor's format library reads Red Faction: Guerrilla's archives and terrain, and writes Armageddon's terrain, its collision and new archives. These are the first steps toward bringing Guerrilla's open world in as new maps; there is nothing for it in the editor yet.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor only: the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.1.0-beta:** the zip holds fresh copies of `rfa_mods.ini` and `console.ini`. Unzip into a new folder and copy your two files and your own overrides across, or unzip over the old folder without replacing those two files.

## Please note

- This is a beta: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
