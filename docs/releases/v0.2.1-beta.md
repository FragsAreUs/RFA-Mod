A fix for RFA-Mod's editor: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.2.1-beta.zip` below.

## What's new since v0.2.0-beta

**The editor is now a 64-bit program.** Every earlier editor was built as a 32-bit program by mistake, which gave it only 2 GB of memory: big levels (a level with its zones around, the dense ones especially) could make it run out of memory and crash. It can now use as much memory as your PC has.

It needs the **64-bit (x64)** .NET 10 Desktop Runtime. If you installed only the x86 one for an earlier version, install the x64 one too. On Linux under Wine or Proton, install the x64 runtime in the prefix the editor runs in.

The launcher, loader and mods are the same as in v0.2.0-beta.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor only: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.2.0-beta:** only the `editor` folder changed. Replace it with the new one, or unzip over the old folder without replacing your `rfa_mods.ini` and `console.ini` (the zip holds fresh copies of both).

## Please note

- This is a beta: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, `logs\editor.log` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
