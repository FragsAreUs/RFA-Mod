The fourth beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.0-beta.zip` below.

## What's new since v0.3.0-beta

**Guerrilla's buildings, in Armageddon.** Rebuild the Guerrilla world (`editor\GuerrillaWorld.exe`) and its towns, bases and camps are there: about 16,400 of Guerrilla's breakable objects (houses, towers, walls, fences, pipes, bridges, signs, rubble) and 6,200 loose props (crates, barrels, boxes, tanks), all where Guerrilla's own map puts them, built from your own copy of Guerrilla. They're Armageddon objects now:
- **They break.** Hit, shoot or blow them up and they come apart where you hit them, piece by piece, with Guerrilla's own pieces, the links that hold them together and the points that hold them to the ground.
- **The Nano Forge rebuilds them**, like Armageddon's own buildings.
- **Loose props are physics objects**: crates and boxes get thrown about by explosions.
- **Guerrilla's textures, decals and look**: each of Guerrilla's materials is moved onto the nearest of Armageddon's shaders.

**The rocks are solid now.** Guerrilla's 8,800 rocks have their own collision: you can stand on them, and charges stick to them.

**Start anywhere.** Every zone of the Guerrilla world has a starting point now, so `level rfg_04_10` (or any `rfg_<column>_<row>`) puts you on the ground in that zone.

**Not there yet:** roads, people, vehicles and plants; Guerrilla's missions and story. Some painted metal (white railings, walkways, wall panels) looks too pale, and windows show as plain white panes where Guerrilla's are dark glass; both are first guesses at how Guerrilla's materials translate to Armageddon's. In one spot (the Ultor site in zone `rfg_10_10`) some small props and rubble may appear a moment after the rest as you get close.

**The editor knows every kind of level object.** It reads the level editing tool's own description of all 68 kinds of objects from your copy of the game (never shipped), so the level editor's inspector now shows each property for what it is: drop-down lists for choices (filled from the game's tables), tick boxes for flags, colours, vectors, boxes and links, with hidden and read-only properties on request. **Add** can make new objects of 42 kinds from nothing (lights, spawn points, triggers, ...), not only copies of existing ones. Moving a navigation point now really moves it in the game (before, only its box moved).

## Rebuilding the Guerrilla world

If you built the world with v0.3.0-beta, build it again to get the buildings and the solid rocks:

1. You need about **3 GB free** where RFA-Mod is (the world is about 2.7 GB now; the buildings come with every zone that has them).
2. Run `editor\GuerrillaWorld.exe` again. It takes two or three minutes. `--props none` builds the world without Guerrilla's buildings and props, as before.
3. In the game, open the console with the ` key and type `level rfg_12_11` (or any zone's name).

Your `GuerrillaDir=` setting and the HUD (`editor\GuerrillaHud.exe`) stay as they are.

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 3 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (two or three minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; delete its files only that way, since one of them also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. Removing `overrides\build\pc\cache\rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx` and `rfg_default.dtodx` takes the world away again.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.3.0-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini` (the zip holds fresh ones; nothing in them is new this time). Then rebuild the Guerrilla world as above.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
