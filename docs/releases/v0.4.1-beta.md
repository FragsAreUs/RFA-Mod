A fix-up beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.1-beta.zip` below.

## What's new since v0.4.0-beta

**Guerrilla's roads.** The Guerrilla world now has Guerrilla's own roads and paved areas (305 of them, with Guerrilla's road textures), laid into the ground the way Armageddon lays its own, instead of plain ground where they should be.

**Much less memory, and a smaller world.** Files that many zones share (the ground's textures, rocks, buildings' parts and their textures) are now kept once in the world's own precache and loaded once, as Guerrilla and Armageddon do with their own worlds, instead of a copy in every zone. In the busiest towns the world needs well under half the memory it did (the worst place went from more than the game sets aside for a level to under half of it), so less waiting for objects to appear as you come near. The built world is about 0.9 GB instead of 2.7 GB.

**Fixes in the Guerrilla world:**
- **No more crashes when blowing up buildings with windows.** Guerrilla's panes of glass now break like the rest of a building.
- **Glass looks like glass**: see-through, with reflections.
- **Rocks sit on the ground** instead of floating over it, and slopes no longer push into buildings or over stairs.
- **The fog takes Guerrilla's colours** over the day (a dusty grey; Armageddon's turned teal at noon). How thick it is is still Armageddon's, so it barely shows yet.

**The editor:**
- **Opens the Guerrilla world.** The explorer lists the new archives your mods add (marked "new, in overrides"), so the world's zones open in the level editor, at the right size.
- **Draws roads** laid into the ground, in Armageddon's own levels and the Guerrilla world (they showed as holes).
- **The Direct3D view no longer crashes** on two of Guerrilla's textures.

**Crash reports** now say which code called which when the game crashes, and keep a dump of the first fault in the game's own code, which helps find what really went wrong.

**Not there yet:** people, vehicles and plants; Guerrilla's missions and story; Guerrilla's fog thickness. Seen from far away (flying the camera up), the ground looks purple: that is how its far-away ground is lit for now, and lighting is next. Some road edges show small dark slivers. Blowing up a big building in a busy town can run out of room for broken pieces ("Ran out of slots for object type (general_mover)"); the pieces past that just don't appear. Painted metal can look too pale.

## Rebuilding the Guerrilla world

Build the world again to get the roads and the memory savings:

1. Run `editor\GuerrillaWorld.exe` again (two or three minutes). It now also writes `overrides\build\pc\cache\rfg_precache.vpp_pc`.
2. In the game, open the console with the ` key and type `level rfg_12_11` (or any zone's name).

A world built with an older version still opens, without the roads and the savings.

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 1 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (two or three minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; delete its files only that way, since one of them also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. Removing `overrides\build\pc\cache\rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx` and `rfg_default.dtodx` takes the world away again.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.4.0-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini` (the zip holds fresh ones; nothing in them is new this time). Then rebuild the Guerrilla world as above.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
