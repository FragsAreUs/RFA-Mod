A beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.2-beta.zip` below.

## What's new since v0.4.1-beta

**Guerrilla's light, district by district.** Each of Guerrilla's districts now has its own sky, light and fog colours over the day, as in Guerrilla, blending into the next as you cross into it, instead of one district's colours over the whole map.

**Guerrilla's colours instead of pink.** Guerrilla tints its whole picture with each district's colour correction, which Armageddon never does, so the world looked pink and lilac. The mod now applies Guerrilla's tint to the light, the sky and the clouds. `ColourCorrection=0` under `[GuerrillaWorld]` in `rfa_mods.ini` turns it off, live.

**Shiny surfaces catch the sun.** Metal, glass and other surfaces with Guerrilla's specular maps now show highlights from the sun (and the moon), with Guerrilla's sharpness. Armageddon only gave shine from its own lamps, so these surfaces looked flat.

**Fixes in the Guerrilla world:**
- **Objects no longer turn into a grid or white** after you load a second zone. The game had room for only so many textures, and the Guerrilla world needs about 2,000 more. Your world now gives it room for 3,500 more.
- **No more white patches and pale metal.** Guerrilla names an empty texture slot "missing"; those were painted white over objects and made their metal shine pale.
- **Crates and small props stay in view** instead of vanishing about 25 m away.
- **Pipes stay on the substations and the reactor core**, and the "Invalidating parent handle" messages are gone: everything attached to something now loads with what it is attached to.
- **EDF vehicle barricades** appear where Guerrilla puts them.
- The game's own warnings while you are in the Guerrilla world go to `logs\rfa_mods.log`, which helps track down problems.

**A better developer console** (the ` key):
- **Easier to read:** a dark panel, bigger text, the line you type on its own strip, commands in amber and errors in red, long lines wrapped.
- **Keeps everything:** 10,000 lines instead of 256, and also written to `logs\console.log`. Scroll back with Page Up / Page Down or the mouse wheel.
- **A mouse:** a cursor, a scroll bar, and clicks that don't reach the game behind the console.
- **The render debug panel** (` + X) is usable: the console moves below it.
- **Settings:** under `[Console]` in `rfa_mods.ini`.

**Not there yet:** people, vehicles and plants; Guerrilla's missions and story; the minimap; effects when props break; Guerrilla's fog thickness and its far mountains. Some cliffs show dark openings. Some walls can look speckled in sunlight.

## Rebuilding the Guerrilla world

Build the world again to get these fixes:

1. Run `editor\GuerrillaWorld.exe` again (two or three minutes). It now also writes `table.vpp_pc\territories.xtbl`, `misc.vpp_pc\bitmaps_pc` and a `rfg_*.dtodx` file for each district into `overrides\build\pc\cache\`.
2. In the game, open the console with the ` key and type `level rfg_12_11` (or any zone's name).

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 1 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (two or three minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; remove it only that way, since one of its files also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. To take the world away, remove the HUD first (`--remove`), then delete `rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx`, `table.vpp_pc\territories.xtbl` and `misc.vpp_pc\bitmaps_pc` from `overrides\build\pc\cache\`.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.4.1-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini`. The zip's `rfa_mods.ini` has new settings: a `[Console]` section and `ColourCorrection=` under `[GuerrillaWorld]`. Copy them into yours, or the defaults are used. Then rebuild the Guerrilla world as above.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
