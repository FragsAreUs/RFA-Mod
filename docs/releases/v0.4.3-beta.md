A beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.3-beta.zip` below.

## What's new since v0.4.2-beta

**Guerrilla's fog.** The Guerrilla world now has Guerrilla's own haze: thicker low down and further away, so distant mountains fade into it and valleys fill with it, with each district's colour over the day. Armageddon's own fog only fades things by distance and never used the time of day's fog, so the mod now draws Guerrilla's fog itself, and the world builder turns Armageddon's fog off in the Guerrilla world. `Fog=` under `[GuerrillaWorld]` in `rfa_mods.ini` makes it thinner or thicker; `Fog=0` turns it off.

**Guerrilla's light and colours on screen.** Armageddon turned the Guerrilla world's picture into what you see with its own settings: a fixed, high exposure, a curve that glares on anything bright, and its own colour grading, which together made everything bright and orange. The Guerrilla world now uses Guerrilla's own tone mapping instead:
- your eyes adapt to how bright the view is, at each district's own speed;
- Guerrilla's exposure for each district and time of day;
- bright light rolls off into white instead of glaring.

The look is darker and more muted, like Guerrilla's. Two settings under `[GuerrillaWorld]`:
- `Exposure=` makes it brighter or darker (1 is Guerrilla's own).
- `ToneMapping=0` brings back Armageddon's own look for comparison.

**You start where Guerrilla starts you.** `level rfg_CC_RR` now puts you at Guerrilla's own player start in the 40 zones that have one, facing the way Guerrilla does, instead of the middle of the zone, which at Parker's start (`rfg_03_12`) was inside a rock. Other zones still start you in their middle.

**No more invisible walls from Armageddon's arena.** Every Guerrilla zone had carried the 28 invisible walls of the Ruin arena the world is built over, so you could walk into walls in open ground (one stood on the way down from Parker's start to the base). Each zone now has Guerrilla's own invisible barriers instead, where Guerrilla puts them.

**Not there yet:** people, vehicles and plants; Guerrilla's missions and story; its far mountains and cliff faces; effects when props break; the minimap. The sky isn't fogged yet: Guerrilla fades its sky into the haze near the horizon. Glass and effects aren't fogged. Some tall structures can stay hanging in the air after their supports are knocked out.

## Rebuilding the Guerrilla world

Build the world again to get the fog, Guerrilla's tone mapping, its player starts and its invisible barriers:

1. Run `editor\GuerrillaWorld.exe` again (two or three minutes).
2. In the game, open the console with the ` key and type `level rfg_12_11` (or any zone's name).

A world built with an older version still opens, with Armageddon's fog and its own colours.

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 1 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (two or three minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; remove it only that way, since one of its files also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. To take the world away, remove the HUD first (`--remove`), then delete `rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx`, `table.vpp_pc\territories.xtbl` and `misc.vpp_pc\bitmaps_pc` from `overrides\build\pc\cache\`.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.4.2-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini`. The zip's `rfa_mods.ini` has three new settings under `[GuerrillaWorld]`: `Fog=`, `ToneMapping=` and `Exposure=`. Copy them into yours if you want to change them; without them Guerrilla's fog and tone mapping are on. Then rebuild the Guerrilla world as above.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
