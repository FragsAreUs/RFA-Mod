A beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.4-beta.zip` below.

## What's new since v0.4.3-beta

**The Guerrilla world is built from scratch.** Until now each Guerrilla zone was built over files taken from Armageddon's own levels, mostly the Ruin arena: its terrain file, its zone file with its environment settings, and the layout of every breakable object. Leftovers of those kept turning up in the Guerrilla world; the arena's invisible walls fixed in v0.4.3 were one. The world builder now writes all of these itself, from Guerrilla's own data and the game's own definitions, so nothing of the arena comes along any more:

- **The terrain.** Each zone's terrain file is written part by part: the ground's collision, the ground's and cliffs' materials, the far-away ground, the ground's surface types and Guerrilla's invisible barriers. Cliff faces now have Guerrilla's own cliff textures, scale and tint (Parker's dark rock, for example) instead of two of the ground's textures. The ground tells the game where it is sand, stone or gravel, as Guerrilla's does, instead of the arena's single surface.
- **The zones.** Each zone's marker, environment settings and player start are made from the game's own object definitions. The arena's settings are gone: its tuned exposure, haze colour, wind, dust and particles. The view distance, fog, bloom and sky are set as before, and the picture looks the same.
- **The buildings and props.** Every breakable object is written the way Armageddon's own tools wrote theirs, with Guerrilla's own settings, which were dropped before:
  - how much of a building must fall before it counts as destroyed (the campaign's targets);
  - bridges, communication towers and force fields marked as such;
  - the names Guerrilla's scripts find their targets by;
  - free-standing buildings held as fixed objects in the physics, as Guerrilla does (before, every building was, even those attached to another);
  - shadows following Guerrilla's settings for the objects whose settings Armageddon's tables don't have.

**Not there yet:** people, vehicles and plants; Guerrilla's missions and story; its far mountains (from high up they look smooth and smeared, with a flat dark red beyond them); effects when props break; the minimap. The sky isn't fogged yet: Guerrilla fades its sky into the haze near the horizon. Glass and effects aren't fogged. Some tall structures can stay hanging in the air while a thin support still holds them. About 2,000 objects use settings Armageddon's tables don't have, so they don't show on the map or smoke when destroyed yet. Still taken from Armageddon's levels: the AI's navigation grid (unused until people come), a floor buried deep under each zone, and the layout of the rock and road materials.

## Rebuilding the Guerrilla world

Build the world again to get the new terrain, zones and buildings:

1. Run `editor\GuerrillaWorld.exe` again (two or three minutes).
2. In the game, open the console with the ` key and type `level rfg_12_11` (or any zone's name).

A world built with an older version still opens, with the arena's leftovers.

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 1 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (two or three minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; remove it only that way, since one of its files also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. To take the world away, remove the HUD first (`--remove`), then delete `rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx`, `table.vpp_pc\territories.xtbl` and `misc.vpp_pc\bitmaps_pc` from `overrides\build\pc\cache\`.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.4.3-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini` (there are no new settings). Then rebuild the Guerrilla world as above.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
